# Protótipo — RW Ar Ideal

Prévia comercial local criada pela NaxelTech a partir da conversa com a RW Ar Ideal e do conteúdo que a empresa publicou no Instagram.

## Abrir

Na pasta do projeto, rode:

```powershell
python -m http.server 5187 --bind 127.0.0.1
```

Acesse `http://127.0.0.1:5187/`. É um site estático: não exige build, backend ou banco de dados.

## O que a prévia mostra

- Serviços e região de atendimento divulgados pela empresa.
- Fotografias de trabalhos reais publicadas no perfil da RW.
- Links diretos para as publicações e para iniciar uma conversa no WhatsApp.
- Layout responsivo e dúvidas frequentes.

A página está marcada `noindex,nofollow`. Antes de publicá-la como site oficial da empresa, confirme identidade visual, uso das fotografias e textos com a RW. Veja as fontes em `docs/FONTES.md`.
